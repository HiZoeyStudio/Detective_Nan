# 火龙果消失事件

这是一个可以直接部署到 GitHub Pages 的静态网页推理游戏基础项目。

## 文件结构

- `index.html`：网页主体
- `css/style.css`：页面样式
- `js/game-data.js`：人物、证据、访谈和时间线数据
- `js/game.js`：页面交互和本地存档
- `images/`：以后放图片
- `audio/`：以后放录音

## 上传到 GitHub

1. 创建一个新的 Public repository。
2. 点击 Add file → Upload files。
3. 把本项目中的所有文件和文件夹上传。
4. 打开 Settings → Pages。
5. Source 选择 Deploy from a branch。
6. Branch 选择 main，文件夹选择 /(root)。
7. 保存后打开 GitHub Pages 提供的网址。

## 修改剧情

主要编辑 `js/game-data.js`。

## 本地预览

双击 `index.html` 即可在浏览器中打开。
