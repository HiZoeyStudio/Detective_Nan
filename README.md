# 有楠必解侦探事务所

一个以“事务所电脑桌面”为入口的网页推理游戏原型。

## 当前体验流程

1. 打开桌面的“邮件”。
2. 阅读委托邮件。
3. 搜索关键字。
4. 进行推理。

进度保存在浏览器的 `localStorage` 中。

## 本地运行

项目兼容直接双击 `index.html` 从登录页开始，也可以通过本地静态服务器或 GitHub Pages 访问。登录后进入 `desktop.html` 桌面。

如需通过本地服务器运行，可在项目目录执行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。
